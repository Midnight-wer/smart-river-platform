## 1. 系统概述

### 1.1 系统简介

**智河通**是一套基于AI与大数据的智慧河长协同治理平台后台管理系统，旨在为各级河长、水务部门提供全方位的河道治理数字化管理工具。

### 1.2 技术架构

| 技术栈 | 说明 |
|--------|------|
| 前端框架 | Vue 3 + TypeScript |
| 构建工具 | Vite 5.x |
| UI框架 | TailwindCSS |
| 状态管理 | Pinia |
| 路由管理 | Vue Router |
| 图表库 | ECharts |
| 地图组件 | 百度地图/自定义地图 |

### 1.3 系统访问

- **访问地址**：http://localhost:5173/
- **数据大屏**：http://localhost:5173/large-screen
- **推荐浏览器**：Chrome、Edge、Firefox（最新版本）

## 2. 登录与权限

### 2.1 登录系统

1. 打开浏览器，输入系统地址
2. 输入用户名和密码
3. 点击"登录"按钮进入系统

### 2.2 权限说明

系统采用基于角色的权限控制（RBAC），不同角色拥有不同的功能权限：

| 角色 | 权限范围 |
|------|----------|
| 超级管理员 | 全部功能 |
| 省级河长 | 省级工作台、查看全省数据 |
| 市级河长 | 市级工作台、管辖区域数据 |
| 县级河长 | 县级工作台、管辖区域数据 |
| 乡镇级河长 | 乡镇级工作台、管辖区域数据 |

## 3. 功能模块详解

### 3.1 工作台（Dashboard）

**路径**：`/dashboard`

**功能描述**：系统首页，展示关键数据概览和快捷操作入口。

**主要内容**：
- 河道数量统计
- 水质达标率
- 巡查任务统计
- 事件处理情况
- 近期预警信息
- 快捷操作按钮

---

### 3.2 河长工作台（Workspace）

**路径**：`/workspace`

**功能描述**：为不同级别河长提供专属工作台，实现分级管理。

#### 3.2.1 省级河长工作台
- **路径**：`/workspace/province`
- **功能**：查看全省河道治理情况、考核下级河长、审批重大事项

#### 3.2.2 市级河长工作台
- **路径**：`/workspace/city`
- **功能**：管理市级河道、督导县级河长、处理市级事件

#### 3.2.3 县级河长工作台
- **路径**：`/workspace/county`
- **功能**：执行巡查任务、处理辖区事件、上报重大问题

#### 3.2.4 乡镇级河长工作台
- **路径**：`/workspace/town`
- **功能**：日常巡查、问题上报、现场处理

---

### 3.3 河道档案（River）

**路径**：`/river`

**功能描述**：管理辖区内所有河道的基础信息档案。

**主要功能**：
| 功能 | 说明 |
|------|------|
| 河道列表 | 查看所有河道，支持搜索、筛选、排序 |
| 河道详情 | 查看河道详细信息、历史数据、关联信息 |
| 河道新增 | 录入新河道信息 |
| 河道编辑 | 修改河道基础信息 |
| 河道删除 | 删除无效河道记录 |

**河道信息字段**：
- 河道名称、编码
- 河道等级（省/市/县/乡镇级）
- 起止位置、河道长度
- 所属流域、行政区划
- 河长信息
- 水质目标

---

### 3.4 河长管理（Chief）

**路径**：`/chief`

**功能描述**：管理系统内所有河长信息，构建数字河长画像。

#### 3.4.1 河长列表
- **路径**：`/chief/list`
- **功能**：查看、搜索、添加、编辑、删除河长信息

#### 3.4.2 数字河长画像
- **路径**：`/chief/portrait`
- **功能**：
  - 河长履职情况分析
  - 巡查轨迹可视化
  - 问题处理效率统计
  - 综合评价得分

---

### 3.5 巡查管理（Patrol）

**路径**：`/patrol`

**功能描述**：管理河长巡查任务，记录巡查轨迹和发现问题。

**主要功能**：
| 功能 | 说明 |
|------|------|
| 任务列表 | 查看待执行和已完成的巡查任务 |
| 任务分配 | 创建并分配巡查任务给河长 |
| 巡查记录 | 查看巡查轨迹、时长、发现问题 |
| 问题上报 | 巡查中发现问题进行上报 |
| 统计分析 | 巡查完成率、覆盖率统计 |

---

### 3.6 水质监测（Water Quality）

**路径**：`/water-quality`

**功能描述**：实时监测河道水质数据，分析水质变化趋势。

**主要功能**：
| 功能 | 说明 |
|------|------|
| 监测站点 | 管理水质监测站点信息 |
| 实时数据 | 查看各站点实时水质数据 |
| 历史数据 | 查询历史水质数据，支持导出 |
| 趋势分析 | 水质变化趋势图表分析 |
| 预警设置 | 设置水质预警阈值 |

**水质指标**：
- pH值
- 溶解氧（DO）
- 氨氮（NH3-N）
- 化学需氧量（COD）
- 总磷（TP）
- 总氮（TN）

---

### 3.7 事件中心（Event）

**路径**：`/event`

**功能描述**：集中管理河道治理相关事件，实现事件全流程跟踪。

**事件类型**：
- 水质异常事件
- 漂浮物事件
- 违规排污事件
- 堤岸损坏事件
- 其他事件

**事件状态流转**：
```
待处理 → 处理中 → 已完成 → 已归档
    ↓         ↓
  已驳回    已关闭
```

**主要功能**：
| 功能 | 说明 |
|------|------|
| 事件列表 | 查看所有事件，支持按状态、类型筛选 |
| 事件详情 | 查看事件详细信息、处理记录 |
| 事件处理 | 分配处理人、填写处理结果 |
| 事件统计 | 事件数量、处理效率统计 |

---

### 3.8 AI智能溯源（AI）

**路径**：`/ai`

**功能描述**：利用AI技术进行污染溯源、水质预测等智能分析。

#### 3.8.1 污染扩散模拟
- **路径**：`/ai/diffusion`
- **功能**：模拟污染物在河道中的扩散过程

#### 3.8.2 排污口指纹识别
- **路径**：`/ai/fingerprint`
- **功能**：识别并标记可疑排污口位置

#### 3.8.3 许可数据库比对
- **路径**：`/ai/compare`
- **功能**：将监测数据与排污许可数据库进行比对

#### 3.8.4 疑似污染源锁定
- **路径**：`/ai/source`
- **功能**：智能分析锁定疑似污染源

#### 3.8.5 目标检测模型
- **路径**：`/ai/detection`
- **功能**：使用YOLO等模型检测水面漂浮物、排污口等

#### 3.8.6 水质预测模型
- **路径**：`/ai/prediction`
- **功能**：基于LSTM等模型预测未来水质变化

#### 3.8.7 污染溯源模型
- **路径**：`/ai/tracing`
- **功能**：追溯污染来源，分析污染路径

#### 3.8.8 履职评估模型
- **路径**：`/ai/evaluation`
- **功能**：AI评估河长履职情况

---

### 3.9 考核管理（Assessment）

**路径**：`/assessment`

**功能描述**：对各级河长进行绩效考核管理。

**考核指标**：
| 指标 | 权重 | 说明 |
|------|------|------|
| 巡查完成率 | 30% | 规定巡查任务完成比例 |
| 问题处理率 | 25% | 发现问题处理完成比例 |
| 水质达标率 | 25% | 辖区河道水质达标比例 |
| 响应时效 | 10% | 事件响应平均时间 |
| 公众满意度 | 10% | 群众投诉处理满意度 |

**主要功能**：
- 考核方案设置
- 月度/季度/年度考核
- 考核结果排名
- 考核报告生成

---

## 5. 操作指南

### 5.1 基础操作

#### 5.1.1 列表操作
- **搜索**：在搜索框输入关键词，点击搜索按钮
- **筛选**：使用筛选下拉框选择筛选条件
- **排序**：点击表头进行升序/降序排序
- **分页**：使用底部分页器切换页码

#### 5.1.2 表单操作
- **新增**：点击"新增"按钮，填写表单，点击"保存"
- **编辑**：点击记录的"编辑"按钮，修改后点击"保存"
- **删除**：点击记录的"删除"按钮，确认后删除
- **批量操作**：勾选多条记录，使用批量操作按钮

#### 5.1.3 数据导出
- 点击"导出"按钮
- 选择导出格式（Excel/PDF）
- 选择导出范围
- 点击"确认导出"

### 5.2 常用流程

#### 5.2.1 巡查任务流程
```
创建任务 → 分配河长 → 河长执行巡查 → 发现问题上报 → 完成任务
```

#### 5.2.2 事件处理流程
```
事件上报 → 审核确认 → 分派处理 → 处理反馈 → 审核结案
```

#### 5.2.3 水质预警流程
```
监测数据异常 → 系统预警 → 河长确认 → 现场核查 → 处理上报 → 预警解除
```

## 6. 常见问题

### Q1：忘记密码怎么办？
**A**：请联系系统管理员重置密码，或使用"忘记密码"功能通过邮箱重置。

### Q2：为什么看不到某些功能菜单？
**A**：可能是因为您的角色权限不足，请联系管理员分配相应权限。

### Q3：数据大屏地图加载不出来？
**A**：请检查网络连接，确保能访问地图服务。如果问题持续，请刷新页面或清除浏览器缓存。

### Q4：如何修改个人信息？
**A**：点击右上角用户头像，选择"个人信息"，在页面中修改后保存。

### Q5：巡查轨迹如何查看？
**A**：进入"巡查管理"→ 点击巡查记录 → 查看轨迹地图。

### Q6：如何导出统计报表？
**A**：进入对应模块 → 点击"统计"或"报表" → 选择时间范围 → 点击"导出"。

### Q7：AI分析结果不准确怎么办？
**A**：AI分析结果仅供参考，请结合实际情况判断。如持续异常，请联系技术人员优化模型。
