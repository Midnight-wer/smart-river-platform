## 5. 识别链路

```
摄像头/上传图片 ──base64──▶ 前端 compressToBlob(最长边1280, q85)
                              │
                              ▼ POST /detect  （同源，经 Vite 代理）
                    Vite dev server ──▶ 127.0.0.1:8000/detect
                                             │
                          decode_image → letterbox(512) → OpenVINO 推理(GPU)
                                             │
                                             ▼ NMS → 坐标还原为「中心点+尺寸」的百分比
                    items: [{target:"塑料瓶", confidence, x, y, width, height}]
```

要点：
- 前端只用同源 `/detect`，Vite 代理转发，避免 CORS；`vite.config.ts` 里 `server.watch.ignored` 排除了训练目录
- 坐标系：x/y 为中心点、width/height 为尺寸，单位均为图片宽高的**百分比**
- 单类模型：界面只可能出现「塑料瓶」
- 性能：OpenVINO 核显端到端 30~80 ms（PyTorch CPU 约 296 ms）；裸推理 核显 8 ms / NPU 15 ms / CPU 63 ms
- 摄像头开关会清空识别框与结果（已验证）

## 6. AI 工程：数据 → 训练 → 发布 → 自检

### 6.1 数据集构成（当前版本：近景定向）

| 类别 | 数量 | 来源 |
|---|---|---|
| 河道近景原图（正） | 440 | m0-n `Plastic-Bottles-Dataset`，只留「框高 ≥3% 图高」的图 |
| ROI 放大裁剪（正） | 440 | 围绕近景瓶裁剪，补不同背景/距离的近景视角 |
| 人工筛选 PET 瓶（正） | 8 | COCO 候选图逐张放大核对后保留的塑料矿泉水瓶 |
| 非瓶子容器（负） | 699 | COCO 玻璃杯/花瓶/马克杯/碗（确认图中无瓶） |
| 河面无瓶图（负） | 200 | 河道实拍无瓶水面 |
| 合计 | train 1520（正 755/负 765）· val 267 | 框 1452 / 233 |

### 6.2 重建数据集

```powershell
cd ai-training
python scripts/build_near_dataset.py --near-height 0.03 --max-crops 1 `
    --coco --coco-selection datasets/reports/curate/selection.json --hard-negatives
```

### 6.3 训练（两阶段，CPU）

```powershell
# 阶段一：通用近景预热
yolo train model=yolov8n.pt data=datasets/near/data.yaml epochs=50 imgsz=512 batch=24 `
    device=cpu workers=10 project=runs name=plastic-bottle-near-coco-512

# 阶段二：河道场景定向微调（从阶段一权重继续）
yolo train model=models/plastic-bottle-near.pt data=datasets/near/data.yaml epochs=25 `
    imgsz=512 batch=24 device=cpu workers=10 lr0=0.003 patience=10 project=runs name=plastic-bottle-water-v1
```

单轮约 2~4 分钟（14 核 CPU，batch 24 / 512 输入）。训练时可用 `patience` 提前停止。

### 6.4 发布与导出

```powershell
Copy-Item runs\detect\runs\plastic-bottle-water-v1\weights\best.pt models\plastic-bottle-near.pt -Force
python scripts/export_onnx.py --weights models/plastic-bottle-near.pt --imgsz 512 `
    --output models/plastic-bottle-near.onnx
# 然后重启 detect_server（它会优先加载 models/plastic-bottle-near.pt / .onnx）
```

### 6.5 常用脚本

| 脚本 | 用途 |

## 7. 关键决策与踩坑（重要，改动前先看）

| 问题 | 根因 | 处理 |
|---|---|---|
| 远景瓶召回只有 0.08~0.15 | SSZ5 数据集标注与图片系统性错位（框全在岸边空地） | 弃用 SSZ5 标注，改用 m0-n 河道瓶数据集 |
| mAP50 训到 0.42 就不动了 | 5592 个框中位数仅 43×28 px（原图 4160×3120），缩到 640 后只剩几像素 | 改为**近景专用**数据集：只留框高 ≥3% 的目标 + ROI 放大裁剪 |
| 训练第 2 轮验证分类损失飙到 15.4 | 把「只有远景小瓶」的图当负样本，与真实语义冲突 | 负样本只用「确实无瓶」和「非瓶子容器」 |
| 模型把玻璃酒瓶/番茄酱瓶当塑料瓶 | COCO `bottle` 类不区分材质，混了大量非 PET 瓶 | 逐张人工核对 96 张候选，只留 8 张 PET 瓶作正样本，其余剔除（不当负样本） |
| 检测服务启动即崩溃 | `load_model` 把 2020 年的老 TFLite 模型排在自训权重前，XNNPACK 报错未捕获 | 自训权重优先；TFLite 仅显式指定时尝试且失败回退 |
| ONNX 导出报「未生成文件」 | `export_onnx.py` 忽略 `--output`，ultralytics 把文件写在权重同目录 | 导出后自动搬运到 `--output` |
| 前端训练期间巨卡、频繁整页刷新 | 训练每次存 `best.pt` 触发 Vite 文件监听 → 整页 reload | `vite.config.ts` 加 `server.watch.ignored` 排除 `ai-training/`、`runs/`、`datasets/`、`logs/`、`models/` |
| 自检脚本中文路径乱码（`娌抽亾`） | `.ps1` 被按 GBK 解析 | 脚本内用 `$PSScriptRoot` 推导路径，不写中文常量；文件保持 UTF-8 BOM |
| `browser_check.mjs` 找不到 playwright-core | ESM 不认 `NODE_PATH` | 把脚本拷到含 `node_modules` 的目录再执行 |
| 训练时电脑卡死 | 训练占满 14 核 | 训练进程降优先级 / 限核；或关掉浏览器与 WPS 等占 CPU 应用 |

## 8. 已知边界与限制

- 极小目标（框面积 <0.2% 图高）召回偏低，河面远景小瓶可能漏检
- 多瓶严重交叠、混入易拉罐等异物的极端场景会漏检
- **室内手持水瓶不再检出**（定向训练的预期结果）；如需兼顾室内场景应单独训一路模型
- 自检的正样本口径是「河面漂浮瓶批量抽查」，不是单张室内图

## 9. 后续任务建议（按优先级）

1. **提召回**：把 imgsz 提到 768/960 重训，或对原图切块（640 tile + 滑窗推理）专门救远景小瓶
2. **扩类别**：若业务要识别其他漂浮垃圾（塑料袋/泡沫/树枝），需另找带标注的漂浮垃圾数据集（当前数据只有瓶子标注）
3. **部署加固**：把 `detect_server` 打成 exe（PyInstaller）随项目分发，去掉 Python 环境依赖
4. **NPU 固化**：若要更省电，把后端固定为 `--backend openvino` 并在 detect_server 里暴露 `device` 参数（NPU 14.7 ms vs 核显 8 ms）
5. **自动化**：给 `after_near_v2.ps1` 加 CI 化（训练完成即触发发布 + 自检 + 产出报告）
6. **前端**：识别页增加「阈值滑块」与「只框最大目标」开关，便于现场调参

## 10. 故障排查速查

| 症状 | 检查 |
|---|---|
| 页面提示识别失败 | `curl http://127.0.0.1:8000/health` 看服务是否在；`GET /detect` 返回 404 说明请求路径错了 |
| 服务起不来 | 看 `ai-training/logs/detect-server.err.log`；OpenVINO 加载失败会自动回退 PyTorch |
| 识别不出瓶子 | 确认加载的是 `models/plastic-bottle-near.onnx`（`/health` 的 model 字段）；确认 `VITE_DETECT_MODE=local` |
| 框位置偏移 | 前端 `VITE_AI_BBOX_SCALE` 默认 1 不要乱调；本地 YOLO 框由模型直接回归 |
| 前端报 `Cannot read properties of null` | Vite 依赖预构建缓存陈旧 → 删 `node_modules/.vite` 后重启 dev server |
| 训练显存/内存不足 | 降 `batch`、`imgsz`；或用 `workers=4` 降低内存占用 |
| 页面卡顿 | 检查是否有训练在跑；确认 `vite.config.ts` 的 `watch.ignored` 已生效 |
