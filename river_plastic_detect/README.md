# 河道漂浮垃圾目标检测系统 · 世界职业技能大赛路演项目

> **项目定位**：面向河道水面巡检与水环境治理的漂浮垃圾（塑料瓶、塑料袋、泡沫包装等）智能识别系统。

## 三、统一依赖与运行方式

### 1. 安装依赖（离线环境请提前下载好离线安装包）

```bash
pip install -r requirements.txt
# ultralytics>=8.3   训练与推理框架
# flask>=3.0        后端接口
# opencv-python>=4.8 图片解码与增强
# pillow>=10.0      图像处理
```

### 2. 一键跑通整条链路

```bash
# 第 1 步：数据准备（1 号）
python data_label/prepare_river_dataset.py --root dataset

# 第 2 步：训练（2 号，小数据集可先 --epochs 3 验证流程）
python train_module/train_river_yolov8n.py --data dataset/river_data.yaml --epochs 60

# 第 3 步：启动后端（3 号），启动后终端需保持运行
python backend_api/app.py --port 5000

# 第 4 步：打开前端（4 号）
#   方式一：浏览器访问 http://127.0.0.1:5000/  （后端托管，无跨域）
#   方式二：直接双击 frontend_show/index.html
```

### 3. 接口速查

| 方法 | 路径 | 说明 | 返回 |
| --- | --- | --- | --- |
| POST | `/api/detect` | 上传河道照片做检测 | `taskId / model / elapsed / image / items / summary` |
| GET | `/api/health` | 服务与模型状态 | `status / model / classes / offline` |

## 五、场景锚点：全程紧扣河道水面巡检

所有设计都围绕河道真实困难展开，答辩时请反复呼应这四点：

1. **水面反光** —— 高光斑会被误判成白色漂浮物；
2. **水面波纹** —— 目标轮廓被扭曲，框会偏；
3. **瓶子半浸水** —— 目标特征残缺，最容易漏检；
4. **水草干扰** —— 颜色纹理接近，容易误报。

对应到四个岗位的解法：

| 痛点 | 1 号 | 2 号 | 3 号 | 4 号 |
| --- | --- | --- | --- | --- |
| 水面反光 | 干扰物不标注 | 造高光斑难例增强 | 置信度阈值可调 | 低置信框标红、计入待复核 |
| 水面波纹 | 框必须贴合完整目标 | 波纹扭曲增强 | 百分比坐标不随缩放漂移 | 灵敏度滑块现场可调 |
| 半浸水 | 框要含水面以下部分 | 高分辨率 640 保细节 | 统计口径按框计数 | 数量直接可视化，漏检看得见 |
| 水草干扰 | 忽略清单过滤 | 贴水草干扰块 | 类别字段可扩展 | 疑似误报进复核队列 |
