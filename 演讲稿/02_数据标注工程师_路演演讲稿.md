## 0:00 一、河道场景为什么难标 + 我们的标注规范（2 分钟）

我是数据标注工程师。

刚才前端把系统完整演示了一遍，评委老师看到的是"照片进去、框出来、数字出来"。那这些框背后的**依据是什么**？是一张张标好的河道照片。**模型能认出半浸水的瓶子，很大程度上是因为标的人标对了**——这一段我讲数据。

河道标注有四个难点：**水面反光**（高光斑像白色漂浮物）、**水面波纹**（目标轮廓被扭）、**瓶子半浸水**（只露瓶盖或半个瓶身）、**水草干扰**（颜色纹理和塑料瓶几乎一样）。

针对这些，我们定了三条硬规矩：

**第一条，框要完整。** 半浸水的瓶子也要按水面线估出水面以下轮廓，整个包进框、四周留 10% 余量——**框只框瓶身中段是最典型的错误标注**，模型学了它框就会飘。

**第二条，框要紧。** 贴着目标边缘画，框越松模型越学不会边界。

**第三条，干扰物不标。** 水草、浮萍、倒影、浮标一律不标。脚本里有一张**干扰物忽略清单**，标错的在整理阶段被自动过滤。通过这张**类别归一化表**，实现**多来源数据统一收敛成"漂浮垃圾"、水草浮萍自动排除**，解决**不同数据集叫法混乱、水草误标污染训练集**的问题：

```python
# 类别归一化：不同来源数据集的叫法统一映射到"漂浮垃圾"
ALIAS_TABLE = {
    "plastic_bottle": TARGET_CLASS, "bottle": TARGET_CLASS,
    "塑料瓶": TARGET_CLASS, "矿泉水瓶": TARGET_CLASS, "塑料袋": TARGET_CLASS,
    ...
}
# 干扰物忽略清单：命中直接丢弃，防止水草、浮萍被当成垃圾教给模型
IGNORE_OBJECTS = {"水草", "浮萍", "浮标", "树枝", "倒影", "weed", "buoy", ...}
```

## 2:00 二、数据清洗：六道自动检查（2 分钟）

标注池进训练集之前，脚本过六道检查：**坏图、缺标注、非法标注行、越界框、重复图、空标注**。

重点看两项核心代码。

通过 **MD5 指纹查重 + 边界夹取修正**，实现**重复图自动剔除、越界框自动拉回画面**，解决**河道巡检连拍导致同批照片重复入库使指标虚高、人工标注手抖把框画出画面产生标注噪声**的问题：

```python
# MD5 指纹查重：同一张图重复导出只保留第一张
digest = file_digest(img_path)          # 分块计算文件 MD5
if digest in seen_hashes:
    stats["重复图"] += 1                 # 计数留痕，报告可查
    continue                            # 丢弃重复样本
seen_hashes[digest] = img_path.name     # 记录指纹

# 越界框修正：标注手抖把框画出画面时，自动夹回边界
if cx - bw / 2 < 0 or cx + bw / 2 > 1 or cy - bh / 2 < 0 or cy + bh / 2 > 1:
    cx = min(max(cx, bw / 2), 1 - bw / 2)   # 中心点夹回画面内
    cy = min(max(cy, bh / 2), 1 - bh / 2)
    bw = min(bw, 1.0)                       # 宽高压到不超边界
    bh = min(bh, 1.0)
    stats["越界框修正"] += 1                 # 修正留痕
```

**第六项"空标注"要展开讲**：画面里确实没有漂浮物的照片，**保留为负样本**。巡检现场大部分照片没有垃圾，负样本教模型"没有就别报"——没有负样本，误报率会高到一线巡检员用两天就弃用。

**工程优化：清洗报告落盘。** 通过**脚本自动生成 Markdown 清洗报告并持久化保存**，实现**每一项清洗、修正、剔除记录留痕可查**，满足**数据溯源**要求——六道检查各处理了多少张，答辩现场直接展示报告文件：

```python
# 清洗报告持久化：统计表 + 划分结果 + 溯源说明，写入 dataset/清洗报告.md
report_path = root / "清洗报告.md"
report_path.write_text("\n".join(lines), encoding="utf-8")
```

## 4:00 三、数据集划分：防止数据泄露（2 分钟）

这是我们数据岗最有价值的一段。

刚开始我们随机按图片划分，结果**同一段河道连续抓拍的前后两张，一张进了训练集、一张进了验证集**——模型等于提前看过验证题答案，指标虚高，到现场立刻露馅。

通过**按采集批次分组整组分配**，实现**同批连拍照片绝不跨集合**，解决**随机划分导致的数据泄露、验证指标虚高**的问题：

```python
# 按采集批次分组：文件名前缀带批次号，同批连拍绝不拆开
groups: dict[str, list[dict]] = {}
for sample in samples:
    groups.setdefault(sample["batch"], []).append(sample)
batch_keys = sorted(groups)
random.shuffle(batch_keys)                            # 固定种子，划分可复现
n_val_batches = max(1, round(len(batch_keys) * VAL_RATIO))  # 8:2 比例
val_batches = set(batch_keys[:n_val_batches])         # 整组分配
```

**工程优化：负样本分层。** 通过**优先把含负样本的批次放进验证集**，实现**训练集/验证集正负样本分布一致**，解决**随机抽批次可能让验证集全是正样本、指标失真**的问题：

```python
# 负样本分层：先抽一个含负样本的批次进验证集，其余补足到 8:2
neg_batches = [k for k in batch_keys if any(not s["boxes"] for s in groups[k])]
first = random.choice(neg_batches)      # 保证验证集有负样本
val_batches = {first}
for key in rest:
    if len(val_batches) < n_val_batches:
        val_batches.add(key)
```

本脚本完成三件事，是整条链路的第一环：
    1) 数据清洗：剔除坏图、空标签、重复图、坐标越界的标注；

    3) 生成 river_data.yaml，供 模型训练工程师直接拿去训练。

输入目录（原始标注池，由标注工具导出）：
    dataset/images/*.jpg   河道巡检现场照片
    dataset/labels/*.txt   YOLO 格式标注，每行 "cls cx cy w h"，坐标为 0~1 归一化值
输出目录：
    dataset/train/images|labels   训练集
    dataset/val/images|labels     验证集
    dataset/river_data.yaml       训练配置文件

依赖：仅 Python 标准库，选手换机器也能直接跑。
运行：
    python data_label/prepare_river_dataset.py --root dataset
"""
from __future__ import annotations

import argparse
import datetime
import hashlib
import random
import re
import shutil
from pathlib import Path

# ---------------- 全局配置 ----------------
# 统一目标类别：河道漂浮垃圾（塑料瓶、塑料袋、泡沫包装等漂浮物统一口径）
TARGET_CLASS = "漂浮垃圾"
CLASS_ID = 0  # 单类别模型，类别 id 固定为 0

# 别名归一化表：不同来源数据集对同一目标的叫法不一样，统一映射到漂浮垃圾
ALIAS_TABLE = {
    "plastic_bottle": TARGET_CLASS,
    "plasticbottle": TARGET_CLASS,
    "bottle": TARGET_CLASS,
    "pet_bottle": TARGET_CLASS,
    "plastic_bag": TARGET_CLASS,
    "bag": TARGET_CLASS,
    "foam": TARGET_CLASS,
    "garbage": TARGET_CLASS,
    "trash": TARGET_CLASS,
    "waste": TARGET_CLASS,
    "litter": TARGET_CLASS,
    "塑料瓶": TARGET_CLASS,
    "塑料瓶身": TARGET_CLASS,
    "饮料瓶": TARGET_CLASS,
    "矿泉水瓶": TARGET_CLASS,
    "瓶子": TARGET_CLASS,
    "塑料袋": TARGET_CLASS,
    "泡沫": TARGET_CLASS,
    "泡沫箱": TARGET_CLASS,
    "塑料片": TARGET_CLASS,
    "垃圾": TARGET_CLASS,
}

# 明确不作为目标的干扰物：出现这些物体不算漂浮垃圾（如误框了水草、浮标）
IGNORE_OBJECTS = {
    "水草", "浮萍", "浮标", "树枝", "树叶", "石头", "鱼", "船", "倒影",
    "weed", "algae", "duckweed", "reflection", "buoy",
}

# 采集批次分组规则：文件名前 4 位数字视为批次号（每 10 张连续抓拍为一批）
BATCH_PATTERN = re.compile(r"^(\d{4})")

# 划分比例：训练集 8 / 验证集 2
VAL_RATIO = 0.2
# 随机种子固定，保证任何人跑出来的划分结果完全一致（可复现）
RANDOM_SEED = 42


def normalize_class(raw_name: str) -> str | None:
    """把各类来源的类别名归一化。返回 None 表示这个名字不是目标或属于忽略清单。"""
    # 去掉首尾空格，统一小写、空格和连字符，避免 "Plastic Bottle" / "plastic-bottle" 匹配不上
    key = raw_name.strip().lower().replace("-", "_").replace(" ", "_")
    # 数字类别 id：YOLO 导出常用 0/1/2 这类编号，本项目源数据为单类（0=瓶类漂浮物）
    if key.isdigit():
        return TARGET_CLASS
    # 命中忽略清单的干扰物直接丢弃
    if key in IGNORE_OBJECTS or raw_name.strip() in IGNORE_OBJECTS:
        return None
    # 查别名表，命中即返回统一类别名
    return ALIAS_TABLE.get(key)


def read_image_size(path: Path) -> tuple[int, int]:
    """用标准库读图片尺寸（JPEG/PNG），不依赖 Pillow，保证脚本零依赖可移植。"""
    # 以二进制方式打开文件，只读文件头
    with path.open("rb") as fp:
        # 读取文件头前 26 字节，足够判断类型并解析尺寸
        head = fp.read(26)
        # PNG 头固定 8 字节，尺寸在第 16~24 字节（大端）
        if head[:8] == b"\x89PNG\r\n\x1a\n":
            import struct
            width, height = struct.unpack(">II", head[16:24])
            return int(width), int(height)
        # JPEG 头为 FF D8，之后逐段扫描找尺寸标记
        if head[:2] == b"\xff\xd8":
            fp.seek(2)
            while True:
                marker = fp.read(2)
                # 读不到完整标记说明文件损坏
                if len(marker) < 2 or marker[0] != 0xFF:
                    return 0, 0
                # 遇到标记后跳过长度字段
                size = fp.read(2)
                if len(size) < 2:
                    return 0, 0
                # SOF0~SOF15 里除 DHT/JPG/DAC 外都带尺寸信息
                if marker[1] in (0xC0, 0xC1, 0xC2, 0xC3, 0xC5, 0xC6, 0xC7,
                                 0xC9, 0xCA, 0xCB, 0xCD, 0xCE, 0xCF):
                    data = fp.read(5)
                    import struct
                    height, width = struct.unpack(">HH", data[1:5])
                    return int(width), int(height)
                # 其他段按长度跳过
                length = int.from_bytes(size, "big")
                fp.seek(length - 2, 1)
    # 不是支持的图片格式
    return 0, 0


def file_digest(path: Path) -> str:
    """计算文件 MD5，用于查重（同一张图重复导出是标注环节最常见的问题）。"""
    # 分块读取，避免大图一次性进内存
    h = hashlib.md5()
    with path.open("rb") as fp:
        for chunk in iter(lambda: fp.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def clean_and_normalize(images_dir: Path, labels_dir: Path) -> tuple[list[dict], dict]:
    """清洗标注池，返回 (合格样本列表, 清洗统计)。"""
    # 统计信息最终会以报告形式打印给评委看
    stats = {"图片总数": 0, "缺标注": 0, "空标注(负样本)": 0, "坏图": 0,
             "重复图": 0, "非法标注行": 0, "越界框修正": 0, "有效正样本": 0}
    # 已出现过的图片指纹，用来查重
    seen_hashes: dict[str, str] = {}
    # 合格样本清单
    samples: list[dict] = []
    # 遍历所有图片（只认常见图片格式）
    for img_path in sorted(images_dir.iterdir()):
        # 跳过子目录，只处理本层文件
        if not img_path.is_file() or img_path.suffix.lower() not in (".jpg", ".jpeg", ".png", ".bmp"):
            continue
        # 图片总数加一
        stats["图片总数"] += 1
        # 找同名标注文件（同名不同后缀）
        label_path = labels_dir / f"{img_path.stem}.txt"
        # 标注文件缺失：无法使用，丢弃
        if not label_path.exists():
            stats["缺标注"] += 1
            continue
        # 读取图片尺寸，尺寸读不出来说明是坏图
        width, height = read_image_size(img_path)
        if width <= 0 or height <= 0:
            stats["坏图"] += 1
            continue
        # 查重：同一张图重复出现只保留第一张
        digest = file_digest(img_path)
        if digest in seen_hashes:
            stats["重复图"] += 1
            continue
        # 记录指纹
        seen_hashes[digest] = img_path.name
        # 解析标注文件
        boxes: list[str] = []
        # 逐行处理标注
        for line in label_path.read_text(encoding="utf-8", errors="ignore").splitlines():
            # 空行直接跳过
            line = line.strip()
            if not line:
                continue
            # 标准 YOLO 行是 5 个字段：类别 + 4 个归一化坐标
            parts = line.split()
            if len(parts) != 5:
                stats["非法标注行"] += 1
                continue
            # 解析类别名与坐标
            cls_name, cx, cy, bw, bh = parts[0], parts[1], parts[2], parts[3], parts[4]
            try:
                cx, cy, bw, bh = float(cx), float(cy), float(bw), float(bh)
            except ValueError:
                stats["非法标注行"] += 1
                continue
            # 归一化类别名，干扰物与非目标直接跳过
            normalized = normalize_class(cls_name)
            if normalized is None:
                continue
            # 宽高非法（非正数）丢弃
            if bw <= 0 or bh <= 0:
                stats["非法标注行"] += 1
                continue
            # 越界修正：框超出画面时把它拉回边界（标注手抖导致）
            if cx - bw / 2 < 0 or cx + bw / 2 > 1 or cy - bh / 2 < 0 or cy + bh / 2 > 1:
                # 把中心点夹在画面内
                cx = min(max(cx, bw / 2), 1 - bw / 2)
                cy = min(max(cy, bh / 2), 1 - bh / 2)
                # 宽高压到不超边界
                bw = min(bw, 1.0)
                bh = min(bh, 1.0)
                # 记录一次修正
                stats["越界框修正"] += 1
            # 统一写成单类别 0，保留 6 位小数
            boxes.append(f"{CLASS_ID} {cx:.6f} {cy:.6f} {bw:.6f} {bh:.6f}")
        # 一行有效框都没有的图，按负样本处理（画面里确实没有漂浮物，这张图很有价值）
        if not boxes:
            stats["空标注(负样本)"] += 1
            samples.append({"image": img_path, "boxes": [], "batch": batch_of(img_path.name)})
            continue
        # 正样本
        stats["有效正样本"] += 1
        samples.append({"image": img_path, "boxes": boxes, "batch": batch_of(img_path.name)})
    # 返回合格样本与统计
    return samples, stats


def batch_of(name: str) -> str:
    """取采集批次号：文件名前 4 位数字。同一批次连续抓拍，姿态高度相似。"""
    # 用正则从前缀里提批次号
    match = BATCH_PATTERN.match(name.replace("river_", ""))
    # 提不到就用文件名前 6 位兜底，保证每张图都有组
    return match.group(1) if match else name[:6]


def split_by_batch(samples: list[dict]) -> tuple[list[dict], list[dict]]:
    """按采集批次做 8:2 划分：同批次只整体落到一个集合，杜绝数据泄露。

    同时做负样本分层：保证验证集批次里包含含负样本的批次，
    避免训练集/验证集正负样本分布偏移导致指标虚高。
    """
    # 固定随机种子，保证划分可复现
    random.seed(RANDOM_SEED)
    # 按批次号把样本分组
    groups: dict[str, list[dict]] = {}
    for sample in samples:
        groups.setdefault(sample["batch"], []).append(sample)
    # 批次列表打乱后顺序分配
    batch_keys = sorted(groups)
    random.shuffle(batch_keys)
    # 验证集需要的批次数
    n_val_batches = max(1, round(len(batch_keys) * VAL_RATIO))
    # ---- 负样本分层：优先把"含负样本的批次"放进验证集 ----
    # 找出所有含负样本的批次
    neg_batches = [k for k in batch_keys if any(not s["boxes"] for s in groups[k])]
    if neg_batches:
        # 先随机抽一个含负样本的批次进验证集，保证两边都有负样本
        first = random.choice(neg_batches)
        val_batches = {first}
        # 其余批次随机补足到目标数量
        rest = [k for k in batch_keys if k != first]
        random.shuffle(rest)
        for key in rest:
            if len(val_batches) < n_val_batches:
                val_batches.add(key)
    else:
        # 没有负样本时按原逻辑取前 N 个批次
        val_batches = set(batch_keys[:n_val_batches])
    # 汇总两边的样本
    train_set, val_set = [], []
    for key in batch_keys:
        (val_set if key in val_batches else train_set).extend(groups[key])
    return train_set, val_set


def write_split(samples: list[dict], out_root: Path, split: str) -> None:
    """把一个集合的图片和标注写到 split 目录。"""
    # 创建图片与标注两个子目录
    img_dir = out_root / split / "images"
    lbl_dir = out_root / split / "labels"
    img_dir.mkdir(parents=True, exist_ok=True)
    lbl_dir.mkdir(parents=True, exist_ok=True)
    # 逐个样本复制
    for sample in samples:
        # 复制图片
        shutil.copy2(sample["image"], img_dir / sample["image"].name)
        # 写标注文件（负样本写空文件，YOLO 中空文件即表示"这张图没有目标"）
        (lbl_dir / f"{sample['image'].stem}.txt").write_text(
            "\n".join(sample["boxes"]) + ("\n" if sample["boxes"] else ""), encoding="utf-8")


def write_yaml(out_root: Path, names: list[str]) -> Path:
    """生成 river_data.yaml，这是 YOLOv8 训练必需的配置文件。"""
    # 组装 yaml 内容，path 用绝对路径避免训练时找不到数据
    content = (
        "# 河道漂浮垃圾检测数据集（由 数据标注工程师的数据整理脚本自动生成）\n"
        f"path: {out_root.as_posix()}\n"
        "train: train/images\n"
        "val: val/images\n"
        f"nc: {len(names)}\n"
        "names: {" + ", ".join(f"{i}: '{n}'" for i, n in enumerate(names)) + "}\n"
    )
    # 写入文件
    yaml_path = out_root / "river_data.yaml"
    yaml_path.write_text(content, encoding="utf-8")
    return yaml_path


def write_report(root: Path, stats: dict, train_set: list[dict], val_set: list[dict]) -> Path:
    """生成 Markdown 清洗报告并落盘持久化，满足数据溯源要求。

    所有清洗、修正、剔除记录都写进这一个文件，答辩时可直接展示。
    """
    # 取当前时间，写进报告头
    now = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    # 分别统计两边的正负样本数
    train_pos = sum(1 for s in train_set if s["boxes"])
    val_pos = sum(1 for s in val_set if s["boxes"])
    # 组装 Markdown 内容
    lines = [
        "# 河道数据清洗报告（自动生成）",
        "",
        f"- 生成时间：{now}",
        f"- 随机种子：{RANDOM_SEED}（划分结果可复现）",
        f"- 验证集比例：{VAL_RATIO}",
        "",
        "## 一、清洗统计",
        "",
        "| 检查项 | 数量 |",
        "| --- | --- |",
    ]
    # 逐项写入清洗统计
    for key, value in stats.items():
        lines.append(f"| {key} | {value} |")
    # 划分结果
    lines += [
        "",
        "## 二、划分结果（按采集批次，防止数据泄露）",
        "",
        f"- 训练集：{len(train_set)} 张（正 {train_pos} / 负 {len(train_set) - train_pos}）",
        f"- 验证集：{len(val_set)} 张（正 {val_pos} / 负 {len(val_set) - val_pos}）",
        f"- 负样本分层：验证集已包含含负样本批次，两边分布一致",
        "",
        "## 三、溯源说明",
        "",
        "- 坏图 / 缺标注 / 非法行：直接剔除，不计入数据集；",
        "- 重复图：MD5 指纹查重，仅保留首次出现；",
        "- 越界框：自动夹回画面边界并计数；",
        "- 空标注：保留为负样本参与训练。",
        "",
        "> 本报告由 prepare_river_dataset.py 自动生成并持久化保存。",
    ]
    # 写盘
    report_path = root / "清洗报告.md"
    report_path.write_text("\n".join(lines), encoding="utf-8")
    return report_path


def main() -> int:
    # 解析命令行参数
    parser = argparse.ArgumentParser(description="河道漂浮垃圾数据集清洗与划分")
    parser.add_argument("--root", default="dataset", help="数据根目录（默认 dataset）")
    parser.add_argument("--val-ratio", type=float, default=VAL_RATIO, help="验证集比例")
    args = parser.parse_args()
    # 拼出各子目录
    root = Path(args.root).resolve()
    images_dir = root / "images"
    labels_dir = root / "labels"
    # 检查输入目录是否存在
    if not images_dir.exists() or not labels_dir.exists():
        print(f"错误：找不到 {images_dir} 或 {labels_dir}，请先准备原始标注")
        return 1
    # 第一步：清洗
    print("=" * 60)
    print("步骤 1/3  数据清洗")
    print("=" * 60)
    samples, stats = clean_and_normalize(images_dir, labels_dir)
    # 打印清洗报告
    for key, value in stats.items():
        print(f"  {key}: {value}")
    # 第二步：按批次划分
    print("=" * 60)
    print("步骤 2/3  按采集批次 8:2 划分（防止数据泄露）")
    print("=" * 60)
    # 清理旧的划分结果，保证每次运行结果一致
    for split in ("train", "val"):
        target = root / split
        if target.exists():
            shutil.rmtree(target)
    train_set, val_set = split_by_batch(samples)
    # 统计正负样本数量（负样本是模型"不误报"的关键）
    train_pos = sum(1 for s in train_set if s["boxes"])
    val_pos = sum(1 for s in val_set if s["boxes"])
    print(f"  训练集: {len(train_set)} 张（正 {train_pos} / 负 {len(train_set) - train_pos}）")
    print(f"  验证集: {len(val_set)} 张（正 {val_pos} / 负 {len(val_set) - val_pos}）")
    # 写文件
    write_split(train_set, root, "train")
    write_split(val_set, root, "val")
    # 生成 Markdown 清洗报告并持久化落盘（数据溯源）
    report_path = write_report(root, stats, train_set, val_set)
    # 第三步：生成训练配置
    print("=" * 60)
    print("步骤 3/3  生成 river_data.yaml")
    print("=" * 60)
    yaml_path = write_yaml(root, [TARGET_CLASS])
    print(f"  配置文件: {yaml_path}")
    print(f"  类别: {CLASS_ID} - {TARGET_CLASS}")
    print(f"  清洗报告: {report_path}（已持久化，可溯源）")
    print("=" * 60)
    print("数据集准备完成，可交给 模型训练工程师训练")
    print("=" * 60)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
