## 1:00 第二部分：前端功能全景（3 分钟）

我们的前端是**一个 HTML 文件**，打开就是一个巡检看板，分四块。

**功能一：服务状态看板（顶部）。** 右上角一盏状态灯，绿灯代表模型就绪、红灯代表服务未连接。因为系统完全离线部署在巡查车一体机上，巡检员必须一眼看出"现在能不能用"。页面还会自动弹出断网提示条，**不会出现点了没反应的空白页面**。

**功能二：上传区（左侧）。** 拖拽或点击上传，附带一个**灵敏度滑块**（置信度阈值）。逆光、起风时调低多捞疑似目标，光线好时调高只要确定目标——**不同工况由巡检员现场决定**。

**功能三：识别结果画布（中间）。** 检测框按置信度分三档颜色：**绿色（≥0.6 可直接派单）、橙色（0.3~0.6 建议复核）、红色（<0.3 疑似反光/水草）**，框上直接标置信度数值。

通过下面这段**画布渲染核心代码**，实现**检测框 + 三档置信度配色 + 框上标注**的可视化，解决**水面反光、水草造成的低置信目标与真实目标混在一起、巡检员无法一眼区分**的问题：

```js
// 遍历后端返回的检测项，逐个画框
items.forEach((it) => {
  // 百分比坐标换算成画布像素坐标（与图片分辨率无关）
  const x = (it.x - it.width / 2) / 100 * canvas.width;
  const y = (it.y - it.height / 2) / 100 * canvas.height;
  const w = it.width / 100 * canvas.width;
  const h = it.height / 100 * canvas.height;
  // 置信度三档配色：绿=可直接派单 橙=建议复核 红=疑似反光/水草
  const color = it.confidence >= 0.6 ? '#2f8f5b'
              : it.confidence >= 0.3 ? '#e08a1e'
              : '#d94f3d';
  ctx.strokeStyle = color;
  ctx.lineWidth = 3;
  ctx.strokeRect(x, y, w, h);            // 画检测框
  ctx.fillStyle = color + '22';          // 半透明填充，突出目标区域
  ctx.fillRect(x, y, w, h);
  ctx.fillText(' 漂浮垃圾 ' + it.confidence.toFixed(2), x + 6, ly + 14); // 框上标置信度
});
```

**功能四：结果解读 + 巡检台账（右侧与底部）。** 统计三宫格（数量/最高/平均置信度），下面是**人话解读**——界面不出现"只有算法看得懂"的词，巡检员读完就知道要不要派工。

通过这段**人话解读函数**，实现**把置信度数字翻译成"能不能派单、要不要复核"的处置结论**，解决**巡检员看不懂专业指标、识别结果落不了地**的问题：

```js
function explainText(data) {
  // 没有目标：直接给"水面正常"结论
  if (!data.summary.count)
    return '✅ 本次巡检未发现漂浮垃圾，该河段水面状况良好。';
  // 高置信目标数：达到派单线的有多少处
  const high = data.items.filter((i) => i.confidence >= 0.6).length;
  // 低置信目标数：可能是反光或水草
  const low = data.items.filter((i) => i.confidence < 0.3).length;
  if (high > 0) {
    let text = '🚨 发现 ' + data.summary.count + ' 处漂浮物，其中 ' + high +
               ' 处位置明确，建议 24 小时内安排打捞。';
    if (low > 0)
      text += '⚠️ 另有 ' + low + ' 处低置信目标，可能是水面反光或水草，请人工复核后再计入台账。';
    return text;
  }
  // 只有中低置信目标：提示先复核
  return '⚠️ 疑似发现 ' + data.summary.count + ' 处漂浮物，可能是反光、波纹或水草造成，建议先人工复核。';
}
```

## 4:00 第三部分：前端工程优化（1 分 30 秒）

除了看得见的功能，我们做了三个工程优化，都是冲着"一线能不能长期用下去"去的：

**优化一：台账本地持久化。** 通过 **localStorage**，实现**巡检记录刷新页面不丢失**，解决**巡查车一体机没有数据库、记录随页面关闭消失**的问题：

```js
// 每次识别完成，台账写入 localStorage 本地持久化
localStorage.setItem('riverPatrolHistory', JSON.stringify(history));
// 页面加载时自动恢复历史记录
history = JSON.parse(localStorage.getItem('riverPatrolHistory') || '[]');
```

**优化二：台账一键导出 CSV。** 通过 **Blob + 下载链接**，实现**巡检记录导出成 Excel 可开的 CSV 文件**，解决**识别结果无法直接交给保洁派工、纸质登记效率低**的问题：

```js
// 组装 CSV（结论口径与看板一致），加 BOM 头防 Excel 中文乱码
```

## 5:30 第四部分：这套前端怎么应对河道四个痛点（2 分 30 秒）

**痛点一：水面反光 → 三档置信度 + 待复核机制。** 反光导致的框置信度天然偏低，自动画红、计入"待人工复核"。**反光不靠模型硬扛，靠人机配合消化**——低置信的现场看一眼，比线上盲猜靠谱。

**痛点二：水面波纹 → 灵敏度滑块 + 每框带置信度。** 波纹让把握度下降，我们把这个下降显式暴露：滑块调低多捞疑似目标人工筛，每个框都带数字方便判断。

**痛点三：瓶子半浸水 → 框要完整 + 数量直接可见。** 漏检是河道巡检最贵的错。标注规范强制"框含水面以下部分"，后端按框计数，前端数量直接呈现——**漏一个就少一个，不让它悄悄漏掉**。

**痛点四：水草干扰 → 红色低置信框 + 复核队列。** 水草框置信度普遍偏低，标红、计入待复核，**不进入直接派单口径**——把模型不确定的部分挡在人工关口之前。

```html
/* 选中文件后：本地预览 + 打开识别按钮 */
function selectFile(file) {
  /* 记住文件 */
  currentFile = file;
  /* 用 FileReader 读取本地图片做预览，不经过后端 */
  const reader = new FileReader();
  /* 读取完成 */
  reader.onload = (e) => {
    /* 创建图片对象 */
    const img = new Image();
    /* 图片加载完成后再画，避免空白 */
    img.onload = () => {
      /* 保存图片对象 */

      /* 画原图 */

      /* 打开识别按钮 */
      detectBtn.disabled = false;

      canvasHint.textContent = '照片已就绪，点击「开始识别」';
    };
    /* 指定图片源 */
    img.src = e.target.result;
  };
  /* 读取二进制图片 */
  reader.readAsDataURL(file);
}

/* ---------------------------------------------------------------

/* 只画原图（未识别状态） */
function drawImageOnly(img) {
  /* 按图片比例自适应画布宽度，保持 900 宽 */
  canvas.width = 900;
  /* 高度按比例算，最多 620，避免过长 */
  canvas.height = Math.min(620, Math.round(900 * img.height / img.width));
  /* 清空画布 */
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  /* 画原图 */
  ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
  /* 隐藏空提示 */
  canvasHint.style.display = 'none';
}

/* 画原图 + 检测框 + 置信度标签 */
function drawResult(img, items) {
  /* 先画原图 */
  drawImageOnly(img);
  /* 逐个画检测框 */
  items.forEach((it) => {
    /* 百分比坐标换算成画布像素坐标 */
    const x = (it.x - it.width / 2) / 100 * canvas.width;
    const y = (it.y - it.height / 2) / 100 * canvas.height;
    const w = it.width / 100 * canvas.width;
    const h = it.height / 100 * canvas.height;
    /* 按置信度分级取颜色：高=绿 中=橙 低=红 */
    const color = it.confidence >= 0.6 ? '#2f8f5b' : (it.confidence >= 0.3 ? '#e08a1e' : '#d94f3d');
    /* 线宽 */
    ctx.lineWidth = 3;
    /* 框颜色 */
    ctx.strokeStyle = color;
    /* 画矩形框 */
    ctx.strokeRect(x, y, w, h);
    /* 半透明填充，让目标区域更醒目 */
    ctx.fillStyle = color + '22';
    /* 填充框内 */
    ctx.fillRect(x, y, w, h);
    /* 画标签底色 */
    const label = ' 漂浮垃圾 ' + it.confidence.toFixed(2);
    /* 计算文字宽度 */
    const tw = ctx.measureText(label).width + 12;
    /* 标签位置：框的上方，贴边显示 */
    const ly = y > 22 ? y - 22 : y;
    /* 底色 */
    ctx.fillStyle = color;
    /* 画标签背景 */
    ctx.fillRect(x, ly, tw, 20);
    /* 文字颜色 */
    ctx.fillStyle = '#ffffff';
    /* 字体 */
    ctx.font = '13px Microsoft YaHei';
    /* 画文字 */
    ctx.fillText(label, x + 6, ly + 14);
  });
}

/* ---------------------------------------------------------------
   五、结果展示：统计 + 人话解读 + 明细
   --------------------------------------------------------------- */
function renderResult(data) {
  /* 取检测项 */
  const items = data.items || [];
  /* 画框 */
  if (currentImage) {
    drawResult(currentImage, items);
  }
  /* 更新三个统计数字 */
  $('countNum').textContent = data.summary.count;
  $('maxNum').textContent = data.summary.maxConfidence ? data.summary.maxConfidence.toFixed(2) : '--';
  $('avgNum').textContent = data.summary.avgConfidence ? data.summary.avgConfidence.toFixed(2) : '--';
  /* 生成人话解读 */
  $('explain').className = 'explain';
  $('explain').innerHTML = explainText(data);
  /* 渲染目标明细列表 */
  const box = $('itemList');
  /* 先清空 */
  box.innerHTML = '';
  /* 没有目标时给一句提示 */
  if (!items.length) {
    box.innerHTML = '<div class="empty">本次未发现漂浮垃圾</div>';
  } else {
    /* 逐条渲染 */
    items.forEach((it, idx) => {
      /* 置信度分级标签 */
      const level = it.confidence >= 0.6 ? 'hi' : (it.confidence >= 0.3 ? 'mid' : 'low');
      const levelText = it.confidence >= 0.6 ? '可直接派单' : (it.confidence >= 0.3 ? '建议复核' : '可能误报');
      /* 拼一条明细 */
      const div = document.createElement('div');
      div.className = 'item';
      div.innerHTML =
        '<div class="row"><b>目标 ' + (idx + 1) + '：' + it.target + '</b>' +
        '<span class="tag ' + level + '">' + it.confidence.toFixed(2) + '</span></div>' +
        '<div style="color:var(--muted);margin-top:4px">位置：横向 ' + it.x + '% / 纵向 ' + it.y + '% ｜ ' + levelText + '</div>';
      /* 追加到列表 */
      box.appendChild(div);
    });
  }
  /* 写入巡检记录 */
  addHistory(data);
}

/* 把专业指标翻译成巡检人员看得懂的话 */
function explainText(data) {
  /* 没有目标 */
  if (!data.summary.count) {
    return '✅ 本次巡检<b>未发现漂浮垃圾</b>，该河段水面状况良好，建议按常规频次继续巡查。';
  }
  /* 高置信目标数量 */
  const high = data.items.filter((i) => i.confidence >= REVIEW_LINE).length;
  /* 低置信目标数量（可能是反光或水草） */
  const low = data.items.filter((i) => i.confidence < 0.3).length;
  /* 总数 */
  const n = data.summary.count;
  /* 有高置信目标：可以派单 */
  if (high > 0) {
    let text = '🚨 本次巡检发现 <b>' + n + ' 处漂浮物</b>，其中 <b>' + high + ' 处</b>位置明确、置信度较高，';
    text += '建议在 <b>24 小时内</b>安排打捞。';
    /* 附带提醒低置信目标 */
    if (low > 0) {
      text += '<br>⚠️ 另有 ' + low + ' 处低置信目标，<b>可能是水面反光或水草</b>，请人工到现场复核后再计入台账。';
    }
    return text;
  }
  /* 只有中低置信目标：提示复核 */
  return '⚠️ 本次巡检疑似发现 <b>' + n + ' 处漂浮物</b>，但置信度偏低，<b>可能是反光、波纹或水草造成</b>，' +
    '建议先人工复核，确认后再安排清理。';
}

/* ---------------------------------------------------------------
   六、巡检记录看板
   --------------------------------------------------------------- */
function addHistory(data) {
  /* 拼一条记录 */
  const conf = data.summary.maxConfidence || 0;
  const record = {
    time: new Date().toLocaleString('zh-CN', { hour12: false }),
    name: data.image.name,
    count: data.summary.count,
    conf: conf,
    avg: data.summary.avgConfidence || 0,
    low: data.items.filter((i) => i.confidence < REVIEW_LINE).length,
  };
  /* 插到最前面 */
  history.unshift(record);
  /* 台账写入 localStorage 本地持久化：刷新页面记录不丢失 */
  localStorage.setItem('riverPatrolHistory', JSON.stringify(history));
  /* 渲染表格 */
  renderHistory();
}

/* 渲染历史表格与累计指标 */
function renderHistory() {
  const body = $('historyBody');
  /* 没有记录时显示空状态 */
  if (!history.length) {
    body.innerHTML = '<tr><td colspan="5" class="empty">暂无巡检记录，上传照片后自动记录</td></tr>';
  } else {
    /* 拼表格行 */
    body.innerHTML = history.map((r) => {
      /* 根据数量给结论 */
      const concl = r.count === 0 ? '水面正常' : (r.low > 0 ? '需复核' : '需清理');
      return '<tr><td>' + r.time + '</td><td>' + r.name + '</td><td>' + r.count +
        '</td><td>' + (r.conf ? r.conf.toFixed(2) : '--') + '</td><td>' + concl + '</td></tr>';
    }).join('');
  }
  /* 累计指标 */
  $('sumPhotos').textContent = history.length;
  /* 累计目标数 */
  $('sumObjects').textContent = history.reduce((s, r) => s + r.count, 0);
  /* 累计待复核数 */
  $('sumReview').textContent = history.reduce((s, r) => s + r.low, 0);
  /* 整体平均置信度 */
  const avg = history.length ? history.reduce((s, r) => s + r.avg, 0) / history.length : 0;
  $('sumAvg').textContent = history.length ? avg.toFixed(2) : '--';
}

$('exportBtn').addEventListener('click', () => {
  /* 没有记录时给出提示 */
  if (!history.length) {
    alert('暂无巡检记录，先上传照片完成一次识别');
    return;
  }
  /* 组装 CSV 表头与数据行 */
  const rows = [['时间', '照片', '漂浮物数', '最高置信度', '待复核数', '巡检结论']];
  history.forEach((r) => {
    /* 结论口径与看板一致：无目标=水面正常，有低置信=需复核，其余=需清理 */
    const concl = r.count === 0 ? '水面正常' : (r.low > 0 ? '需复核' : '需清理');
    rows.push([r.time, r.name, r.count, r.conf ?? '', r.low, concl]);
  });
  /* 加 BOM 头，防止 Excel 打开中文乱码 */
  const csv = '\ufeff' + rows.map((r) => r.join(',')).join('\n');
  /* 生成下载链接并触发下载 */
  const blob = new Blob([csv], { type: 'text/csv;charset=utf-8' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = '河道巡检台账.csv';
  a.click();
});
```
